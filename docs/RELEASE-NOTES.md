# Release Notes — EmprendeLink DWF

Este documento registra los cambios relevantes realizados en EmprendeLink durante el desarrollo del proyecto.

Cada versión importante deberá documentar:

- nuevas funcionalidades;
- cambios relevantes;
- correcciones;
- limitaciones conocidas;
- cambios de arquitectura;
- cambios de base de datos;
- cambios de dependencias;
- instrucciones especiales de actualización cuando corresponda.

---

## Convención de versiones

Se utilizará inicialmente una numeración simple:

`MAJOR.MINOR.PATCH`

Ejemplos:

- `0.1.0`
- `0.2.0`
- `1.0.0`

Durante el desarrollo académico podrán utilizarse versiones previas a `1.0.0`.
